2698 Data Extractor

One bookmark for reading lists out of the Top War web game: alliance members (698N, S, W and C) and the Whitebeard ranking.

1 · Install (once, on a computer)

Drag this onto your bookmarks bar:

2698 Data Extractor

No bookmarks bar? Press Ctrl+Shift+B (Mac: Cmd+Shift+B) to show it. Can't drag? , then make a new bookmark and paste it as the URL.

The bookmark only loads the extractor from this site, so new features arrive without installing it again.

2 · Use

  1. Open the Top War web game and click 2698 Data Extractor. Click it again to hide or show the panel. Clicked anywhere else, it opens this site in a new tab.
  2. Alliance members: tap 698N, 698S, 698W or 698C (or Read all four). The game opens each member list, the extractor reads it and closes it again, and the Alliance roster card on the site is updated. Send Base CP to sheet sends the Base CP of every alliance read to Alliance Rosters.
  3. Whitebeard: tap Read while the event runs. It opens the ranking, loads every page (about 25 seconds) and updates the Whitebeard card on the site. Pick 698N, W, S, C or Other and tap Send to sheet.
  4. Snow Train: open a train's Unit Details window, tap Read (this updates the Snow Train card on the site), then Send to sheet to add every player's March CP to SS P2 Snow Train.

It only opens windows you could open yourself and reads what the game loads for them. It never changes anything in the game. Each read is kept in this browser, so Send still works after the game is reloaded. Player IDs go only to the site's server, to match players between reads; they are never shown.
