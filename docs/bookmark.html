Ranking bookmark

One click on a Top War ranking screen adds Date, Name, Points, Rank and Alliance to the Game rankings sheet — the four main alliances, or everyone else.

1 · Install (once, on a computer)

Drag this onto your bookmarks bar:

2698 Data Extractor

No bookmarks bar? Press Ctrl+Shift+B (Mac: Cmd+Shift+B) to show it. Can't drag? , then make a new bookmark and paste it as the URL.

2 · Use

  1. Open the Top War web game and the Whitebeard ranking.
  2. Click 2698 Data Extractor in the bookmarks bar. The game only loads about 30 rows at first: press Load all in the panel to load the rest (or scroll to the bottom yourself).
  3. In the panel, pick 698N, W, S, C or Other, check the count, and press Send to sheet.

Each send is added below the lists already in the sheet, dated by the game's day (UTC). The bookmark only reads what the game has already loaded on your screen: it sends nothing to the game and taps nothing.
